# DESIGN.md: вариант «Space» (по промту 2, Planet Jumping)

Источник направления: `дизайн/дизайн промт 2` в папке проекта. Промт описывает одностраничный лендинг; здесь он перенесён на многостраничный сайт агентства.

## Токены
| Роль | Значение |
|---|---|
| Фон | `#090807`, панели `rgba(255,255,255,.06)` |
| Текст | `#FFFFFF`, вторичный `rgba(255,255,255,.72)` |
| Линии | `rgba(255,255,255,.48)` и мягкие `.16` |
| Шрифты | Inter вместо SF Pro, Oswald вместо Aalto (у Aalto нет кириллицы), Google Fonts |
| Заголовки | Oswald uppercase, на внутренних H1 `clamp(44px, 6.4vw, 118px)` |
| Кнопки | пилюли: белая с точкой и стеклянная (`backdrop-filter`) |
| Анимации | `cubic-bezier(.22,1,.36,1)` и `cubic-bezier(.16,1,.3,1)` |
| Поля | `clamp(18px, 1.95vw, 28px)` |

## Главная
- Холст-портал из промта: прелоадер с видео (один раз за сессию), стыковка логотипа, скруглённый прямоугольник-портал с наклоном, переход между тремя состояниями.
- Три состояния вместо трёх планет: «Поиск», «Нейросети», «Авито». Название, факты и ссылка берутся из шапки главной страницы (`channels`).
- Видео и изображение Меркурия подключены по адресам из промта.

## Внутренние страницы
- Первый экран: фон из изображения Меркурия, крупный H1, лид, две кнопки, строки фактов.
- Контент: инфографики «этапы», «цифры», «сравнение», блок «Из практики», перебивка CTA, FAQ на `<details>`, карточки кейсов и «Смотрите также».
- Боковая колонка с оглавлением и CTA на широких экранах.
- Собственный курсор только на устройствах с мышью, полноэкранное меню.

## Отступления от промта (осознанные)
- Один HTML-файл заменён на Astro: каждая страница отдаётся готовым HTML, это нужно для SEO.
- Логотип из промта не используется: это знак другой студии. Вместо него свой знак «ББ».
- Тексты про планеты заменены на каналы заявок агентства. Числа и формулировки взяты из контента сайта.
- При `prefers-reduced-motion` прелоадер пропускается, CSS-анимации и наклон портала отключаются.
